# The Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One zoomable map, planet to street, with street maps, sub-metre
satellite and Google's own views, carrying El Niño's measured effects,
today's ocean, recent floods, the Niño regions and the documented impact
regions, read out for any point tapped or found.

**Architecture:** The storm desk's Web Mercator engine (`stormdesk._JS`)
learns XYZ street-map tiles, a per-layer maximum zoom and Esri's placeholder
rule. A new module, `elnino/worldmap.py`, owns the El Niño and street-map
parts: the layer catalogue, the colour maps, the page payload
(`data["enso"]`), the server-rendered "El Niño now" section, its CSS and its
script (`worldmap._JS`), which `stormdesk.script()` splices into the desk's
script at the `/*WORLDMAP*/` marker so both share one scope.
`stormdesk.page(state, focus)` writes `map.html` (`focus="world"`) and
`storms.html` (`focus="storms"`).

**Tech Stack:** Python 3.10 standard library; vanilla JS in the page; canvas
for the composite, inline SVG for marks; unittest; node for the page's own
functions; Playwright for one browser pass if a page can be loaded.

**Spec:** `docs/superpowers/specs/2026-09-28-world-map-design.md`

**Execution:** inline in this session (executing-plans). Where a step gives
behaviour and exact assertions rather than every line of glue, the executor is
the plan's author and holds the context; every test is still written first
and watched failing.

## Global Constraints

- Standard library only; Python 3.10.11; no build step; no key, token or
  account anywhere in the repository or the page.
- External services are only those in the spec's verified table: Esri
  `server.arcgisonline.com` tiles, Esri World Geocoder
  `geocode.arcgis.com/.../findAddressCandidates` (no `forStorage`), OSM
  `tile.openstreetmap.org` (served pages only), NASA GIBS, Google's
  `maps.google.com/maps?...&output=embed|svembed` frames and Google Maps /
  Earth URLs.
- Nothing is requested from Google before the reader presses a Google button;
  nothing is sent to the geocoder before the reader chooses its row.
- Composites are drawn exactly as the atlas draws them: grids from
  `atlasview._grid_payload()`, ramp `--d0..--d10` (`fields.ramp_css()`),
  full scale PRECIP 3.0 mm/day and AIR 1.6 °C, rainfall negated, cells
  failing the season's t test at 0.16 of full weight while the mask is on,
  weight `max(0.42, 1 - (px - 90) / 420)` past 90 screen pixels a cell,
  overall opacity 0.58, adjustable.
- Maximum zoom 19 on a map layer, 13 on a NASA layer (`MAXZ = 13` stays);
  El Niño tile overlays hidden above zoom 12.
- Placeholder rule: 16 x 16 samples; at least 200 of 256 opaque and within 3
  of RGB 204,204,204 on every channel.
- Page text wears text tokens; official and data colours sit beside a label;
  light and dark from tokens; touch targets at least 44 px; only `#map` sets
  `touch-action: none`; no `http://` URL and no `<script src` in a page; the
  desk page says "cannot be prevented" exactly once.
- `storms.json` (schema 1) keeps its layers and fields as they were; the new
  catalogue and payload are the page's.
- Tests: `python -m unittest discover -s tests` from the repo root, green
  before every commit (662 at start).
- Commit messages end with
  `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
  Do not push. Do not merge.

3. A run with pieces missing (no assessment, no impacts, no forecast, no
   weekly SSTs): both pages still build, the El Niño section says what did not

4. The page opened from a file (no Referer, `Origin: null`): OpenStreetMap is

5. Hostile or odd text in the search box and the address hash (`&`, `#`,

   the way out, escaped on the way in, ignored or clamped without breaking the

```python
def _nearest_lon(values: tuple[float, ...], target: float) -> int:
    """Nearest centre on a 0..360 axis, measured the short way round: 359.87
    is 0.38 from 0.25, not 358.62."""
    best, at = float("inf"), 0
    for i, value in enumerate(values):
        gap = abs((value - target + 180.0) % 360.0 - 180.0)
        if gap < best:
            best, at = gap, i
    return at
```

and in `sample`: `xi = _nearest_lon(lons, lon % 360.0)`. Grep `_index(` for

```js
  function nearestLon(values, target) {
    // The short way round: 359.87 is 0.38 from 0.25, not 358.62.
    var best = 0, bestd = 1e9, i;
    for (i = 0; i < values.length; i++) {
      var d = Math.abs(((values[i] - target + 540) % 360) - 180);
      if (d < bestd) { bestd = d; best = i; }
    }
    return bestd > 4 ? -1 : best;
  }
```

```js
  var NODATA = {}, MAPS = {};
  function xyzUrl(template, z, x, y) {
    return template.replace("{z}", z).replace("{y}", y).replace("{x}", x);
  }
  function present(name, z, c, r) { return {z: z, c: c, r: r}; }
  function xyzCells(l, template, name) {
    var out = [], seen = {};
    var gz = clamp(Math.round(S.z), 0, l.zoom), n = Math.pow(2, gz), o = origin(), size = o.W / n;
    var c0 = Math.floor(-o.left / size), c1 = Math.floor((S.w - o.left - 0.01) / size);
    var r0 = Math.max(0, Math.floor(-o.top / size)), r1 = Math.min(n - 1, Math.floor((S.h - o.top - 0.01) / size));
    for (var r = r0; r <= r1; r++) for (var c = c0; c <= c1; c++) {
      var t = present(name, gz, c, r), m = Math.pow(2, t.z), id = name + "/" + t.z + "/" + t.c + "/" + t.r;

      out.push({id: id, z: t.z, c: t.c, r: t.r, clip: "", name: name, key: null, map: l.id,

    }
    return out;
```

```js
    var ax = gridAxes(name), lats = ax[0], lons = ax[1];
    var r = nearestAt(lats, lat), c = nearestLon(lons, ((lon % 360) + 360) % 360);
    var dy = lats.length > 1 ? Math.abs(lats[1] - lats[0]) / 2 : 0;
```

```js
  var GEOCODER = "https://geocode.arcgis.com/arcgis/rest/services/World/GeocodeServer/findAddressCandidates";
  function geocodeUrl(q) {
    return GEOCODER + "?SingleLine=" + encodeURIComponent(q) + "&maxLocations=6&outFields=Match_addr,Type&f=json";
  }
  function geocoded(answer) {
    var list = answer && answer.candidates;
    if (!Array.isArray(list)) return [];
    return list.slice(0, 6).filter(function (c) { return c && c.location && isFinite(c.location.x) && isFinite(c.location.y); })
      .map(function (c) {
        var a = c.attributes || {}, e = c.extent;
        return {kind: "address", label: a.Match_addr || c.address || "", deep: true, zoom: 16,
                sub: (a.Type || "Address") + " \u00b7 Esri World Geocoder",
                lon: +c.location.x, lat: +c.location.y,
                box: e && isFinite(e.xmin) && isFinite(e.ymax) ? {x0: mx(e.xmin), x1: mx(e.xmax), y0: my(e.ymax), y1: my(e.ymin)} : null};
      });
  }
  function searchRow(text) {
    var q = String(text || "").trim();
    if (fold(q).length < 3 || coordinate(q)) return null;
    return {kind: "search", q: q, label: "Search streets and addresses for \u201c" + q + "\u201d",
            sub: "Sends these words to Esri\u2019s World Geocoder"};
  }
```
