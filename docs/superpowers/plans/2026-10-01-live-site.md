# The Live Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The public site refreshes itself every hour, and a page left open takes each new run on its own, without a manual reload and without losing the reader's place.

**Architecture:** GitHub Actions runs `track.py` every hour through a new `publish.sh` and publishes with the existing `publish.py`, carrying the database and cached feeds between runs in the Actions cache. Each run writes `run.json` last; every page names its run in a `<meta name="elnino-run">` mark. One script, `live.SCRIPT`, in every page, asks for `run.json` each minute and takes a new run in place (storm desk, map) or by loading again with the reader's place handed over in `sessionStorage` (dashboard, atlas). `publish.py` refuses a set of pages that does not name one run.

**Tech Stack:** Python 3.10+ standard library (3.12 on GitHub); plain ES5-style JavaScript inline in the pages; node for the JavaScript tests; POSIX `sh`; GitHub Actions (checkout v7, setup-python v7, cache v6).

**Spec:** `docs/superpowers/specs/2026-10-01-live-site-design.md`

## Global Constraints

- Standard library only; no new dependencies; pages stay self-contained (no `<script src`, no `http://` anywhere in a page).
- Python 3.10 on this machine and 3.12 on GitHub: the suite passes on both.
- Never run `track.py` for a check: it writes `data/elnino.db`. Tests patch `pipeline.run`.
- The working tree is CRLF (`core.autocrlf=true`); the README is edited through a Python script; never `sed -i`.
- The full suite runs only as `python <scratchpad>/r19/batches.py <logdir> 8` (each batch its own process).
- Commits never skip hooks or signing; each message ends with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- The follower sets every word a reader sees as text, never as markup (`innerHTML` never appears in `live.SCRIPT`).
- Timings, from the spec: ask every 60 s; load after 2 min left alone; the "Now showing" note 6 s; a run that does not arrive is tried again after 2, 5, 10, then every 15 minutes.
- Notice words, from the spec: "The site has a new run, from 01 Oct 2026 11:12 UTC." with an **Update now** button; "Now showing the run of 01 Oct 2026 11:12 UTC."
- Workflow values, from the spec: `cron: "12 * * * *"`, `workflow_dispatch`, push to `main`; `concurrency: {group: live-site, cancel-in-progress: false}`; `permissions: contents: write, actions: write`; checkout with `persist-credentials: false`; Python `"3.12"`; `timeout-minutes: 30`; cache key `tracker-state-<run_id>-<run_attempt>`, restored by the prefix `tracker-state-`.
- GitHub receives only snapshot commits authored `VillaKeth <170055060+VillaKeth@users.noreply.github.com>`, over HTTPS (see Rollout).

## Review Focus

1. **One run written two ways.** A page whose mark says `2026-10-01T11:12:00+00:00` while `run.json` says `2026-10-01T11:12:00Z` shows the site's run: no offer, no take, no load. Pinned in Task 2.
2. **A stale copy after a load.** A page loaded again that still shows the old run (a CDN or cache copy) waits out its pause, loads once more, and then arrives and says so. Pinned in Task 2.
3. **A tab hidden for hours.** Its timers frozen while two runs went by, a tab shown again asks at once, offers only the latest run, gives the reader two minutes, and loads once. Pinned in Task 2.
4. **Any address.** The beacon is asked beside the page whether the page is the site's folder (`/elnino-tracker/`), a page with a `#view=` hash, or the local server. Pinned in Task 2.
5. **A real run's pages.** Everything one offline run writes is published as one run and names no path of this machine. Pinned in Task 7.

```python
"""Pages that follow the site.

Every page names the run it was drawn from, in a mark in its head, and a run
writes ``run.json`` after every other file, naming itself. Served over HTTP, a
page asks for ``run.json`` each minute and takes a run it does not show: the
storm desk and the map in place, reading themselves again; the dashboard and
the atlas by loading again once the reader has left them alone, the reader's
place handed over in ``sessionStorage`` and put back. A run that does not
arrive is gone for again after a pause that grows, so a page never loops, and
a page that cannot hand its place over never loads again on its own: it only
offers to.
"""

from __future__ import annotations

import json
from pathlib import Path

from .svg import esc

# What a page asks for to learn which run the site serves.
BEACON = "run.json"


def write_run(run_at: str, path: Path) -> Path:
    """The beacon: the run the files beside it are of. Written last, so a page
    that finds a new run named in it finds every file of that run there."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps({"run_at": run_at}), encoding="utf-8")
    return path


# Run before the page is first painted: the theme a page loading again for a
# new run handed over, so a reader in the dark theme sees no flash of light.
_THEME = """(function () {
  try {
    var handed = JSON.parse(window.sessionStorage.getItem("elnino-live:" + location.pathname));
    var theme = handed && handed.place && handed.place.theme;
    if (theme === "light" || theme === "dark") document.documentElement.setAttribute("data-theme", theme);
  } catch (e) { /* nothing handed over: the page opens in its own theme */ }
})();"""


def head(run_at: str | None) -> str:
    """What a page carries in its head: the run it shows, and the script that
    puts back a theme handed over. A page with no run time names no run, and
    so never follows the site."""
    if not run_at:
        return ""
    return f'<meta name="elnino-run" content="{esc(run_at)}">\n<script>{_THEME}</script>'
```

```python
# The follower, in every page before the page's own script. A page calls
# elninoLive.follow() once it is drawn: with {take: f} to take a new run in
# place, f reading the page again and promising when that is done (and then
# naming the run through elninoLive.shows(doc)); or with nothing, or
# {keep: f, restore: g} for state of its own, to load again for it.
SCRIPT = r"""var elninoLive = (function () {
  "use strict";
  // The site is asked which run it serves every minute. A page that loads
  // again for a new run waits until the reader has left it alone for two
  // minutes, and names the run it then shows for six seconds. A run that does
  // not arrive is gone for again after 2, 5 and 10 minutes, then every 15.
  var ASK = 60000, QUIET = 120000, NOTE = 6000, PAUSES = [2, 5, 10, 15];
  // Where a page hands its place to itself across a load, one key a page; the
  // script in the page's head (live.head) reads the theme from it.
  var KEY = "elnino-live:" + location.pathname;
  var MONTHS = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];

  var opts = {}, store = null, note = null, timer = 0, quietSince = 0;
  var want = {run: null, tries: 0, next: 0};  // the run last gone for, and when it may be again
  var pending = null;                         // the run the notice offers
  var taking = false;                         // a run is being taken in place

  function noop() {}
  function num(v) { return typeof v === "number" && isFinite(v) ? v : 0; }
  function mark() { return document.querySelector('meta[name="elnino-run"]'); }
  function shown() { var m = mark(); return m ? m.getAttribute("content") : null; }
  // One run however it is written: "...Z" and "...+00:00" are one moment.
  function same(a, b) {
    if (a === b) return true;
    var x = Date.parse(a), y = Date.parse(b);
    return !isNaN(x) && x === y;
  }
  function pad(n) { return (n < 10 ? "0" : "") + n; }
  function when(run) {
    var d = new Date(Date.parse(run));
    if (isNaN(d.getTime())) return run;
    return pad(d.getUTCDate()) + " " + MONTHS[d.getUTCMonth()] + " " + d.getUTCFullYear() + " " +
           pad(d.getUTCHours()) + ":" + pad(d.getUTCMinutes()) + " UTC";
  }

  // ---- the place a page hands itself ----------------------------------------
  // sessionStorage, when the browser keeps it for this page: a private window,
  // or a site whose data are blocked, may keep none.
  function storage() {
    try {
      var s = window.sessionStorage;
      s.setItem(KEY + "?", "1");
      s.removeItem(KEY + "?");
      return s;
    } catch (e) { return null; }
  }
  function handed() {
    try { return JSON.parse(store.getItem(KEY)); } catch (e) { return null; }
  }
  function hand(record) {
    try { store.setItem(KEY, JSON.stringify(record)); return true; } catch (e) { return false; }
  }
  function forget() {
    try { store.removeItem(KEY); } catch (e) { /* left, it is read once more and found stale */ }
  }
  // Where the reader is: the scroll, the theme, each section open or shut by
  // its summary's words (a new run's page may have a section more or fewer, so
  // a count would set the wrong ones), and what the page keeps of its own.
  function place() {
    var sections = [], list = document.querySelectorAll("details > summary");
    for (var i = 0; i < list.length; i++) sections.push([list[i].textContent, list[i].parentNode.open]);
    return {x: window.scrollX, y: window.scrollY, sections: sections,
            theme: document.documentElement.getAttribute("data-theme"),
            kept: opts.keep ? opts.keep() : null};
  }
  // What storage hands back is read like input: the page's own state only
  // from an object, a section only from its words and a flag, the scroll only
  // from numbers.
  function putBack(p) {
    if (!p || typeof p !== "object") return;
    if (opts.restore && p.kept && typeof p.kept === "object") opts.restore(p.kept);
    var left = Array.isArray(p.sections) ? p.sections.slice() : [];
    var list = document.querySelectorAll("details > summary");
    for (var i = 0; i < list.length; i++) {
      for (var j = 0; j < left.length; j++) {
        if (Array.isArray(left[j]) && left[j][0] === list[i].textContent && typeof left[j][1] === "boolean") {
          list[i].parentNode.open = left[j][1];
          left.splice(j, 1);
          break;
        }
      }
    }
    window.scrollTo(num(p.x), num(p.y));
  }

  // ---- the notice -------------------------------------------------------------
  // Its words are set as text, never as markup.
  function say(words, offer) {
    note.textContent = "";
    if (!words) return;
    var p = document.createElement("p");
    p.textContent = words;
    if (offer) {
      var button = document.createElement("button");
      button.type = "button";
      button.textContent = "Update now";
      button.addEventListener("click", function () { load(true); });
      p.appendChild(button);
    }
    note.appendChild(p);
  }

  // ---- following the site -------------------------------------------------------
  function due(run) { return run !== want.run || Date.now() >= want.next; }
  // Going for a run counts a try at it, and holds the next try back by a
  // pause that grows with them.
  function goFor(run) {
    var tries = run === want.run ? want.tries + 1 : 1;
    want = {run: run, tries: tries, next: Date.now() + PAUSES[Math.min(tries, PAUSES.length) - 1] * 60000};
  }
  function consider(run) {
    if (same(run, shown())) { withdraw(); return; }
    if (run === pending || taking || !due(run)) return;
    if (opts.take) { takeInPlace(run); return; }
    pending = run;
    say("The site has a new run, from " + when(run) + ".", true);
    if (!store) return;
    if (document.hidden) load(false);
    else settle();
  }
  function takeInPlace(run) {
    goFor(run);
    taking = true;
    Promise.resolve().then(opts.take).catch(noop).then(function () { taking = false; });
  }
  // The run offered is loaded once the reader has left the page alone long
  // enough; a reader still at it puts it off.
  function settle() {
    clearTimeout(timer);
    var wait = quietSince + QUIET - Date.now();
    if (wait <= 0) load(false);
    else timer = setTimeout(settle, wait);
  }
  // Loading again for the run offered, its place and its pause handed over
  // first. Asked for, the page loads whatever storage does; on its own, only
  // when they were handed over, or it could load again and again.
  function load(asked) {
    clearTimeout(timer);
    goFor(pending);
    var handedOver = store !== null && hand({run: want.run, tries: want.tries, next: want.next, place: place()});
    if (handedOver || asked) { location.reload(); return; }
    store = null;  // storage refused the write: from here on the page only offers
  }
  function withdraw() {
    if (pending === null) return;
    pending = null;
    clearTimeout(timer);
    say("");
  }
  // A page loaded again: the place handed over is put back, once, and either
  // the page shows the run it was loaded for and says so for a moment, or it
  // does not, and that run waits out its pause.
  function arrive() {
    var record = handed();
    if (!record || typeof record !== "object") return;
    putBack(record.place);
    var run = typeof record.run === "string" ? record.run : null;
    if (run !== null && !same(run, shown())) {
      want = {run: run, tries: Math.max(1, Math.floor(num(record.tries))),
              next: Math.min(num(record.next), Date.now() + PAUSES[PAUSES.length - 1] * 60000)};
      hand(want);
      return;
    }
    forget();
    if (run === null) return;
    say("Now showing the run of " + when(run) + ".");
    setTimeout(function () { if (pending === null) say(""); }, NOTE);
  }
  // What the site answers is read like input: only a run named in words counts.
  function ask() {
    fetch(new URL("run.json", location.href), {cache: "no-store"})
      .then(function (r) { return r.ok ? r.json() : null; })
      .catch(function () { return null; })
      .then(function (beacon) {
        var run = beacon && beacon.run_at;
        if (typeof run === "string" && run) consider(run);
      });
  }

  function follow(options) {
    if (!/^https?:$/.test(location.protocol) || !shown()) return;
    opts = options || {};
    if (!opts.take) {
      note = document.createElement("div");
      note.className = "livenote";
      note.setAttribute("role", "status");
      document.body.appendChild(note);
      store = storage();
      if (store) arrive();
      quietSince = Date.now();
      ["pointerdown", "pointermove", "keydown", "wheel", "touchstart", "scroll"].forEach(function (type) {
        window.addEventListener(type, function () { quietSince = Date.now(); }, {capture: true, passive: true});
      });
    }
    // A page shown again asks at once, and gives a reader just come back to it
    // the time to read before it loads; a page put away loads what it offered.
    document.addEventListener("visibilitychange", function () {
      if (!document.hidden) { quietSince = Date.now(); ask(); }
      else if (pending !== null && store) load(false);
    });
    window.addEventListener("online", ask);
    ask();
    setInterval(ask, ASK);
  }
  // A page that took a run in place names it, from the page it read.
  function shows(doc) {
    var mine = mark(), theirs = doc.querySelector('meta[name="elnino-run"]');
    if (mine && theirs) mine.setAttribute("content", theirs.getAttribute("content"));
  }

  return {follow: follow, shows: shows};
})();"""
```

```js
  function span(min) {
    if (min < 60) return min + ' min';
    var h = Math.floor(min / 60), m = min % 60;
    if (h < 48) return h + ' h' + (m ? ' ' + m + ' min' : '');
    return Math.round(h / 24) + ' days';
```

```js
  // A page loading again for a new run hands over what the reader had: the
  // view, the layers and the point picked, its dossier scrolled where it was.
  // What comes back is read like input: a value that is not one of the
  // atlas's own leaves that part as the page opens.
  function own(table, key) { return Object.prototype.hasOwnProperty.call(table, key); }
  function finite(x) { return typeof x === "number" && isFinite(x); }
  function keep() {
    return { view: { lon: view.lon, lat: view.lat, dpp: view.dpp }, variable: variable,
             season: season, fade: fade, composite: composite, base: base,
             show: { borders: show.borders, rivers: show.rivers, places: show.places },
             marked: marked && { lon: marked.lon, lat: marked.lat }, dossier: panel.scrollTop };
  }
  function restore(kept) {
    if (typeof kept.variable === "string" && own(D.grids, kept.variable)) { variable = kept.variable; }
    if (D.seasons.indexOf(kept.season) >= 0) { season = kept.season; }
    if (typeof kept.fade === "boolean") { fade = kept.fade; }
    if (typeof kept.composite === "boolean") { composite = kept.composite; }
    if (typeof kept.base === "string" && own(BASE, kept.base)) { base = kept.base; }
    if (kept.show && typeof kept.show === "object") {
      Object.keys(show).forEach(function (layer) {
        if (typeof kept.show[layer] === "boolean") { show[layer] = kept.show[layer]; }
      });
    }
    var v = kept.view;
    if (v && finite(v.lon) && finite(v.lat) && finite(v.dpp) && v.dpp > 0) {
      view = { lon: v.lon, lat: v.lat, dpp: v.dpp };
      clampView();

    var m = kept.marked;
    if (m && finite(m.lon) && finite(m.lat) && Math.abs(m.lat) <= 90) {
      pick(m.lon, m.lat);
      if (finite(kept.dossier)) { panel.scrollTop = kept.dossier; }
    }
```

```python
def _named_run(name: str, data: bytes) -> str | None:
    """The run a page names, as it names it; None when it names none, or names
    it in words no time can be read from."""
    if name.endswith(".html"):
        head, closed, _ = data.partition(b"</head>")
        found = _MARK.search(head) if closed else None
        run = html.unescape(found.group(1).decode("utf-8", "replace")) if found else None
    else:
        try:
            run = json.loads(data).get(_NAMED[name])
        except (ValueError, AttributeError):
            run = None
    if not isinstance(run, str):
        return None
    try:
        _moment(run)
    except ValueError:
        return None
    return run


def _check_one_run(pages: dict[str, bytes], when: str) -> None:
    """Every page names latest.json's run, compared as moments. A page of
    another run is half of two runs, and a page that names a run run.json
    never names would load again forever looking for it."""
    faults = []
    for name, data in pages.items():
        if name == "latest.json":
            continue
        run = _named_run(name, data)
        if run is None:
            faults.append(f"{name} names no run")
        elif _moment(run) != _moment(when):
            faults.append(f"{name} names the run of {run}")
    if faults:
        raise PublishError(f"{'; '.join(faults)}, where latest.json names the run of {when}: "
                           "run track.py again")
```

```python
def lay_out(out_dir: Path, site: Path, home: Path | None = None) -> str:
    """Write the last run's pages into site as the site serves them, and
    return the run's time as latest.json gives it. Raises PublishError, having
    written nothing, when a page is missing, empty or cut off, latest.json gives
    no run time, a page names this machine's home folder, or a page is of
    another run or names none."""
    pages = _read(out_dir)
    when = _run_at(pages["latest.json"])
    _check_home(pages, Path.home() if home is None else home)
    _check_one_run(pages, when)
    for name, source in PAGES.items():
        (site / name).write_bytes(pages[source])
    # Served as written: without this file GitHub puts the pages through Jekyll.
    (site / ".nojekyll").write_bytes(b"")
    return when
```

```yaml
# The live site: run the tracker every hour and publish the run to GitHub
# Pages, so the site is never much more than an hour behind NOAA's feeds.
# Open pages follow it on their own (elnino/live.py).
name: Live site

on:
  schedule:
    # Twelve past each hour: the products land on the hour, and GitHub queues
    # scheduled runs longest at the top of it.
    - cron: "12 * * * *"
  workflow_dispatch:
  push:
    branches: [main]

# One at a time: two runs never publish over each other or race on the state.
concurrency:
  group: live-site
  cancel-in-progress: false

permissions:
  contents: write  # to push gh-pages
  actions: write   # to keep the schedule from pausing

jobs:
  run:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    steps:
      - uses: actions/checkout@v7
        with:
          persist-credentials: false

      - uses: actions/setup-python@v7
        with:
          python-version: "3.12"

      # The last run's database and cached downloads: the alerts this run is
      # reconciled against, and the copy a failed feed falls back on. The
      # dated archive stays out; nothing reads it back.
      - name: Restore the tracker's state
        uses: actions/cache/restore@v6
        with:
          path: |
            data/elnino.db
            data/raw/*.cache
            data/raw/*.meta.json
          key: tracker-state-${{ github.run_id }}-${{ github.run_attempt }}
          restore-keys: tracker-state-

      - name: Run the tracker and publish the run
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          gh auth setup-git
          code=0
          ./publish.sh --remote "https://github.com/$GITHUB_REPOSITORY.git" || code=$?
          case $code in
            0) ;;
            1) echo "::notice title=Alerts open::Published with WARNING or CRITICAL alerts open." ;;
            3) echo "::warning title=Degraded run::Published, but some feeds failed and fell back on their last copy." ;;
            *) exit "$code" ;;
          esac

      - name: Save the tracker's state
        if: ${{ !cancelled() }}
        uses: actions/cache/save@v6
        with:
          path: |
            data/elnino.db
            data/raw/*.cache
            data/raw/*.meta.json
          key: tracker-state-${{ github.run_id }}-${{ github.run_attempt }}

      # without activity; a workflow enabled from its own run keeps going.
      - name: Keep the schedule from pausing
        if: ${{ !cancelled() && github.event_name == 'schedule' }}
        continue-on-error: true
```
